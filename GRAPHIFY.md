# Граф знаний Graphify

Этот проект использует **Graphify** для создания интерактивного графа знаний из кодовой базы. Это позволяет Claude Code быстрее понимать отношения, зависимости и архитектуру.

**⚠️ ВАЖНО: Все общение об этом проекте должно происходить на русском языке.**

## 📊 Статистика графа

- **416 узлов** — символы кода, типы, импорты, конфигурация
- **623 связи** — отношения (вызовы, импорты, ссылки, содержит)
- **28 сообществ** — семантические кластеры связанного кода
- **Стоимость**: $0.19 (однократная стоимость экстракции)
- **Последняя сборка**: 2026-05-28 из коммита `04f9c208`

## 🎯 Центральные узлы (Наиболее связанные)

1. **ScreenRecorder** (34 связи) — Основной синглтон-класс записи
2. **compilerOptions** (18 связей) — Конфигурация TypeScript
3. **scripts** (15 связей) — npm скрипты
4. **getWindowByName()** (14 связей) — Утилита управления окнами
5. **FfmpegSettings** (10 связей) — Интерфейс конфигурации записи

## 🚀 Быстрые команды

### Понимание концепции
```bash
graphify explain "ScreenRecorder"
graphify explain "FfmpegSettings"
graphify explain "IPC"
```

### Поиск соединений
```bash
graphify path "ScreenRecorder" "startRecording"
graphify path "main.ts" "FFmpeg Binary"
```

### Запрос по темам
```bash
graphify query "запись экрана"
graphify query "FFmpeg"
graphify query "обработчики IPC"
```

### Обновление графа
```bash
graphify update .    # После изменений кода (только AST, без стоимости API)
```

## 💡 Когда использовать Graphify

### Вместо grep:
```bash
# ❌ grep "ScreenRecorder" -r src/
# ✅ graphify explain "ScreenRecorder"
# ✅ graphify query "как используется ScreenRecorder"
```

### Для понимания архитектуры:
```bash
# ✅ graphify path "main.ts" "FFmpeg Binary"
# ✅ Читайте GRAPH_REPORT.md для обзора высокого уровня
```

### Для навигации по изолированному коду:
```bash
# ✅ graphify explain "FfmpegDevice"
# ✅ graphify path "A" "B" для прямых соединений
```

## 🔄 Поддержание графа в актуальном состоянии

После значительных изменений кода:
```bash
graphify update .
```

Это обновляет граф, используя только AST анализ (без вызовов API, мгновенно).

Если ваши изменения не появляются в графе:
```bash
graphify extract .
```

Это перезапускает полную семантическую экстракцию (использует API, стоит ~$0.20).

## 📖 Архитектурные инсайты

### Основные компоненты (Сообщество 5)
- **ScreenRecorder** — Оркестратор записи
- **FfmpegSettings** — Схема конфигурации

- Коммуникация множественных окон через IPC

## 🛠 Решение проблем

**Граф кажется неполным?**
- Проверьте статус экстракции в GRAPH_REPORT.md (должно быть 90%+ EXTRACTED)
- Пересоберите с помощью: `graphify extract .`

**Запросы не возвращают результаты?**
- Попробуйте разные ключевые слова или используйте `graphify explain` для определённого символа
- Проверьте GRAPH_REPORT.md для точных имён узлов

**Граф устарел после изменений кода?**
- Запустите `graphify update .` (только AST, мгновенно)
- Или `graphify extract .` для полной переиндексации
