# Dst-Recorder

Приложение для записи экрана на macOS. Живёт в строке меню и пишет в MP4 экран целиком или выбранную область вместе со звуком: ваш голос из микрофона (в том числе AirPods) и звук компьютера — YouTube, собеседников в созвоне, уведомления.

Никаких дополнительных программ и драйверов не нужно: ни FFmpeg, ни BlackHole, ни агрегатных устройств в «Настройке Audio-MIDI». Всё записывает сам Electron (Chromium): экран — через ScreenCaptureKit, звук компьютера — через Core Audio Tap.

> **Платформы.** Основная платформа — **macOS 14.2 и новее** (запись звука компьютера через Core Audio Tap). Electron 45 запускается на macOS 13+, но звук компьютера на 13.x не гарантируется. Сборка под Windows (`pnpm build:win`) использует тот же механизм записи, но не проверялась.

## Возможности

- **Запись экрана или области**: выбор монитора или перетаскиваемая рамка для записи произвольной области.
- **Звук компьютера и микрофон** одной дорожкой. Работает с любыми наушниками: звук компьютера пишется до вывода на устройство, поэтому в записи есть и вы, и то, что вы слышите.
- **Выбор микрофона с индикатором уровня**: рядом со списком микрофонов шкала громкости — сразу видно, что выбран тот микрофон, в который вы говорите.
- **Качество**: пресеты 720p / 1080p / 2K / 4K; пресеты выше разрешения монитора скрываются.
- **Пауза / продолжение** без обработки файла после записи.
- **Плавающий таймер** с кнопками старт / пауза / стоп и быстрыми настройками.
- **Меню в строке меню (трей)**: старт/стоп, текущие экран и звук, длительность записи в заголовке трея, когда таймер скрыт.
- **Рамка** вокруг записываемого экрана (опционально).
- **Мониторы можно подключать и отключать** на ходу: список экранов обновляется сам, а если отключить записываемый монитор, запись сохраняется.
- **Файл не теряется при сбое**: запись сохраняется на диск каждую секунду.
- Низкая нагрузка: видео кодирует аппаратный H.264-кодировщик Mac.

## Установка

Скачайте DMG из [Releases](../../releases) (есть сборки под Apple Silicon и Intel).

Приложение не подписано сертификатом Apple Developer, поэтому macOS может сообщить, что оно «повреждено». Быстрое решение:

```bash
xattr -cr /Applications/Dst-Recorder.app
```

Другие способы — в [INSTALLATION.md](INSTALLATION.md).

### Разрешения macOS

При первом запуске приложение само запросит **Микрофон** и **Запись экрана и системного звука**, а при первой записи со звуком компьютера macOS спросит ещё **«Запись только системного звука»** — всё от имени Dst-Recorder, больше ничего разрешать не нужно. После включения записи экрана приложение нужно перезапустить — macOS предложит это сама. Если доступ не выдан, приложение покажет пошаговую инструкцию с кнопкой «Открыть настройки». Подробнее — в [INSTALLATION.md](INSTALLATION.md#после-первого-запуска).

## Использование

После запуска иконки в Dock нет — приложение работает из строки меню (иконка камеры).

| Пункт меню | Что делает |
|---|---|
| ▶️ Начать запись | Запись выбранного экрана с текущими настройками |
| ⚙️ Настройки | Окно настроек: экран, качество, микрофон, звук компьютера, папка, рамка |
| ⏱️ Таймер | Плавающая панель управления записью |
| 📐 Область | Рамка для выбора области записи (перетаскивайте её мышью) |
| 📂 Открыть папку с записями | Открывает папку сохранения |

**Звук.** В настройках выберите микрофон («Микрофон по умолчанию» — тот, что выбран в системе, или конкретное устройство, или «Без микрофона») и включите «Записывать звук компьютера». Шкала справа от микрофона показывает уровень, пока открыты настройки.

**Запись области.** Откройте «Область», расположите рамку, нажмите старт на таймере. Записывается то, что внутри рамки, на том мониторе, где она стоит. Во время записи рамка «прозрачна» для кликов, таймер скрывается — остановить запись можно из меню в строке меню.

### Где что лежит

| Что | Путь |
|---|---|
| Записи (по умолчанию) | `~/Desktop/Dst-Recorder/REC_ДД-ММ-ГГГГ_ЧЧ_ММ_СС.mp4` |
| Настройки | `~/Library/Application Support/dst-recorder/dst-settings.json` |
| Логи | `~/Library/Logs/dst-recorder/main.log` |

Формат: MP4 (фрагментированный), видео H.264 30 fps, битрейт подбирается по размеру кадра (около 1–2 Мбит/с для 1080p), звук AAC 128 кбит/с стерео 48 кГц.

## Разработка

### Требования

- macOS 14.2+ (для записи и проверки)
- Node.js 20+
- pnpm 8+

### Быстрый старт

```bash
git clone <repository-url>
cd dst-recorder
pnpm install   # postinstall (install-electron) скачает бинарник Electron
pnpm dev       # Vite + Electron с hot reload
```

В dev-режиме разрешения на запись экрана, системного звука и микрофон выдаются приложению, из которого запущен процесс (Terminal, iTerm, IDE).

### Команды

| Команда | Назначение |
|---|---|
| `pnpm dev` | Режим разработки |
| `pnpm compile` | Проверка типов + сборка Vite |
| `pnpm lint` / `pnpm lint-ci` | ESLint (CI-режим падает на предупреждениях) |
| `pnpm build:mac` | DMG для x64 и arm64 в `release/` |
| `pnpm build:win` | NSIS-установщик (не проверялся) |

### Стек

Electron 45 · Vue 3 + TypeScript · Vite 7 (`vite-plugin-electron`) · Bootstrap 5 · electron-log · electron-builder.

### Архитектура

**Окна.** Пять `BrowserWindow`, создаются при старте и дальше только показываются/скрываются. Все грузят один Vue-бандл с hash-роутингом:

| Окно | Маршрут | Назначение |
|---|---|---|
| Main | `/` | Настройки |
| Timer | `/timer` | Плавающий таймер и управление записью |
| SelectAria | `/select-aria` | Рамка выбора области |
| Border | `/border` | Рамка вокруг экрана во время записи (игнорирует мышь) |
| Capture | `/capture` | Невидимое окно, в котором идёт запись |

**Состояние.** Источник истины — singleton `ScreenRecorder` в main-процессе. `setSettings()` проверяет настройки, сохраняет их в `dst-settings.json` и рассылает всем окнам (`ExposedRecorder.UPDATED_SETTINGS`). Статус записи раз в секунду рассылается через `ExposedRecorder.UPDATED_STATE_TIMER`.

**Запись.** Всё делает Chromium в скрытом окне Capture, main им управляет через `webContents.executeJavaScript` (`capture-bridge.ts` ↔ `window.dstCapture`):

1. `getDisplayMedia` — экран и звук компьютера. Какой экран, решает main в `setDisplayMediaRequestHandler` (`audio: "loopback"`). Звук компьютера на macOS 14.2+ Chromium берёт через Core Audio Tap — для этого в Info.plist есть `NSAudioCaptureUsageDescription` (`electron-builder.json`); без ключа звук молча пустой. Chromium сам масштабирует картинку до размера из `capture-plan.ts`.
2. `getUserMedia` — микрофон без шумодава и автогромкости.
3. `AudioMixer` сводит микрофон (×2) и звук компьютера в одну стереодорожку на 48 кГц. Частота фиксирована: иначе микшер подстраивается под AirPods в режиме гарнитуры (24 кГц) и портит весь звук.
4. Для области `VideoCrop` вырезает её из каждого кадра (`MediaStreamTrackProcessor` → `VideoFrame` с `visibleRect` → `MediaStreamTrackGenerator`) — без копирования пикселей.
5. `MediaRecorder` кодирует в MP4 (H.264 аппаратно + AAC) и раз в секунду отдаёт кусочек фрагментированного MP4. Кусочки по IPC уходят в main, `RecordingFile` дописывает их в файл.

Пауза — `MediaRecorder.pause()`. Остановка — `stop()`: main ждёт, пока придут все кусочки, и закрывает файл. Если захват оборвался сам (отключили монитор, macOS отозвала доступ, упал процесс окна), записанное сохраняется.

**Разрешения и подпись.** Разрешения запрашиваются от имени приложения в `src/permissions.ts` (`desktopCapturer.getSources` для записи экрана, `askForMediaAccess` для микрофона). `builder/after-pack.js` подписывает пакет ad-hoc, чтобы macOS надёжно узнавала приложение и не сбрасывала разрешения.

**Особенности упаковки.** `asar: false`. В пакет попадают только `dist/`, `dist-electron/`, иконки и production-зависимости. Значка в Dock нет (`LSUIElement` в Info.plist, в dev — `activationPolicy: accessory`) и не завершается при закрытии окон.

### CI и релизы

`.github/workflows/build-mac.yml` собирает DMG на каждый push/PR в `main` и выкладывает артефакты (вкладка Actions → запуск → Artifacts). На тег `v*` автоматически создаётся GitHub Release с DMG:

```bash
git tag v1.0.1 && git push origin v1.0.1
```

Не забудьте поднять `version` в `package.json`.

CI ставит зависимости строго по `pnpm-lock.yaml` (`--frozen-lockfile`) той версией pnpm, что указана в `packageManager` в `package.json`. Поэтому после любого изменения зависимостей запустите `pnpm install` и закоммитьте `pnpm-lock.yaml` вместе с `package.json` — иначе сборка в CI упадёт на установке.

Все библиотеки интерфейса (Vue, Bootstrap) Vite встраивает в сборку, поэтому они в `devDependencies` и в приложение не попадают; в `dependencies` только то, что нужно main-процессу во время работы (`electron-log`).

## Решение проблем

| Симптом | Что проверить |
|---|---|
| Запись не стартует, диалог про доступ | «Запись экрана и системного звука» и «Микрофон» в «Конфиденциальность и безопасность», затем перезапуск |
| В записи нет звука компьютера | Включён ли переключатель «Записывать звук компьютера»; в «Конфиденциальность и безопасность → Запись экрана и системного звука» включён Dst-Recorder в разделе «Только системный звук»; macOS 14.2+ |
| В записи нет голоса | Выбран ли нужный микрофон — шкала уровня в настройках должна реагировать на голос |
| AirPods стали звучать хуже, пока открыты настройки | Так macOS переключает их в режим гарнитуры, когда открыт их микрофон (шкала уровня). Закройте настройки — качество вернётся |
| Нужные подробности | `~/Library/Logs/dst-recorder/main.log` — параметры каждой записи и ошибки захвата |

## Известные ограничения

- Проверено только на macOS.
- FPS (30) и битрейт не настраиваются из UI.
- Громкость микрофона относительно звука компьютера зашита в код (`src/capture/audio-mixer.ts`).
- Звук может идти примерно на 0,1 с позже картинки (особенность захвата Chromium).
- Интерфейс только на русском.
- Приложение не подписано и не нотаризовано.
